产品文档站（模拟宿主）

本页用于验证通用知识库插件能否在任意网站中独立工作。 整页只有一处集成代码，且只依赖知识库自身的公开接口。

这个页面验证什么

  • 不依赖宿主专有接口：页面没有任何 Trace / Run / Execution 概念，也没有 Agent Insight 的登录态。
  • 样式隔离：本页对 button 和 div 设了激进的全局样式，插件仍应保持自身外观。
  • 开箱可用：宿主只需一段 <script> 标签。

集成代码（完整内容）

加载中…

本页自身已经是一段集成示例：通过 URL 参数 ?kb=<知识库id>&key=<公开key> 把配置传给页面， 页面再注入插件。不需要再手工往控制台注入 script —— 那样会产生第二个插件实例，两个悬浮球互相干扰。

要在自己的网站里集成，把上面的 src 换成你的知识库服务地址、 data-kb-id 与 data-api-key 换成 kb show <知识库> 的输出即可。

建议的验证问题

  • 「服务默认端口是多少？」 — 应给出带引用的准确回答
  • 「数据库端口和日志保留期分别是多少？」 — 答案跨多个文档，每条陈述各自挂引用
  • 「如何申请火星移民签证？」 — 知识库未覆盖，应明确拒答并提示补充方向
  • 追问「那它和前面提到的端口有关系吗？」 — 验证多轮上下文

网络请求检查

打开浏览器开发者工具的网络面板，筛选 /api/public/kb/。 应只能看到以下路径，不应出现任何 Agent Insight 专有接口：

  • POST /api/public/kb/{kbId}/chat 或 GET .../chat/stream
  • GET /api/public/kb/{kbId}/config
  • GET /api/public/kb/{kbId}/chunks/{chunkId}（点击引用时）
  • POST /api/public/kb/feedback（提交反馈时）
