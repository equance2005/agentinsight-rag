6. 第一步验收清单

逐条对照，全部可在本页或外部测试页完成。

组验收项在本页如何验证
A CLI 与网页分别导入；md/txt/Word/Excel/PDF 正确解析 用「网页上传」选多种格式；CLI 用 kb import
B 内容增删改查、增量同步、问答对录入 CLI kb sync / kb qa add；改动源文件后再同步并观察「向量：计算 N，复用 M」
C 插件在外部站点与宿主页面都能完成普通文档问答 本页挂载 + 打开外部测试页；对照两者行为
D 多轮上下文、流式输出、悬浮入口与对话框交互 用「提问（流式）」观察增量输出；插件内连续追问
E 有答案 / 跨文档 / 未覆盖 / 证据冲突 四类问题的表现 依次提问，核对「裁决」「引用」「引用可点开定位」
F 不认可反馈与未解决问题被记录，可供维护者处理 插件内点 👎；CLI kb gaps / kb resolve 复查闭环
